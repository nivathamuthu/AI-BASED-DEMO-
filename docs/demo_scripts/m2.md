# Module 2 demo script (about 2 minutes)

Open http://localhost:8010/prompts/ after:

```powershell
docker compose exec web python manage.py eval_prompts
```

1. Point at the header. It names the LLM provider and the model, so the score is traceable.
2. Point at v1's mean, then v2's mean. v2 is higher.
3. Open one answer row. v1 quoted the first sentence and missed the part number. v2 quoted the sentence that contains it.
4. Open an unanswerable row, such as the torque question. v1 invented an answer. v2 says unknown.
5. Say that every call is a Pydantic object, and a failed validation is retried and written to the LLM call log.

# Module 3 demo script (about 2 minutes)

Load the corpus first (`.\make.ps1 demo`), then open http://localhost:8010/rag/.

1. Ask `What does AD 2023-14-09 require?` on Vector, then on BM25, then on Hybrid. With the mock embedder both lists usually find the directive, because the mock encoder is a lexical hash. The citation under the answer shows the document, the page and the section.
2. Switch to Hybrid+rerank. The default rerank is lexical. The cross-encoder is off unless `RERANK_ENABLED=true` and the image was built with `--build-arg INSTALL_ML=1`.
3. Ask `What torque in newton-metres is specified for the pin?` The page should abstain: "I don't know."
4. Run `.\make.ps1 eval` and read the hit@5 table. The header names the LLM and the embedding provider. To measure a real encoder, set `EMBEDDINGS_PROVIDER=openai` and `OPENAI_API_KEY`, then `python manage.py reembed` and run the eval again. The old mock vectors are not comparable, so the reembed step is required.
